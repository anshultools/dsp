# Practical 03 — Computation of DTFT

## Write-Up

**Aim:** To compute and plot the magnitude and phase responses of the Discrete-Time Fourier Transform (DTFT) using MATLAB.

**Theory:** The DTFT converts a discrete-time sequence into a continuous function of angular frequency: (X(e^{j\omega})=\sum_{n=-\infty}^{\infty}x[n]e^{-j\omega n}). Magnitude represents frequency-component strength, while phase represents phase shift.

**Procedure:** Set the frequency range from `-pi` to `pi`; calculate the frequency-domain expression; find magnitude with `abs` and phase with `angle`; plot both.

**Conclusion:** The DTFT magnitude and phase responses were computed and plotted using MATLAB.
