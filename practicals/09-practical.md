# Practical 09 — Design and Implementation of Low-Pass FIR Filter Using Hamming Window

## Aim
To design and implement a low-pass Finite Impulse Response (FIR) filter using a Hamming window in MATLAB and observe its frequency response and filtering effect.

## Apparatus
MATLAB

## Theory

### 1. Low-pass FIR filter
A **low-pass filter** allows low-frequency components to pass while attenuating higher-frequency components.

An FIR filter has a finite-duration impulse response. Its output is calculated using the present and a fixed number of previous input samples:

\[
y[n]=\sum_{k=0}^{M}b[k]x[n-k]
\]

where:
- \(x[n]\) is the input sequence.
- \(y[n]\) is the filtered output sequence.
- \(b[k]\) are the FIR filter coefficients.
- \(M\) is the filter order.

### 2. Composite input signal
Three sinusoidal signals with frequencies of 10 Hz, 20 Hz, and 30 Hz are generated and added:

\[
x_1(t)=\sin(2\pi f_1t)
\]
\[
x_2(t)=\sin(2\pi f_2t)
\]
\[
x_3(t)=\sin(2\pi f_3t)
\]

The composite signal is:

\[
x(t)=x_1(t)+x_2(t)+x_3(t)
\]

The sampling frequency is selected as four times the highest input frequency:

\[
F_s=4f_{\max}=4\times30=120\,\text{Hz}
\]

The sampling interval is:

\[
T_s=\frac{1}{F_s}=\frac{1}{120}\,\text{seconds}
\]

### 3. Hamming window
A window is applied to limit the ideal filter impulse response to a finite number of samples. The Hamming window reduces sidelobes in the frequency response compared with a rectangular window.

For a Hamming window of length \(L\), the window sequence is:

\[
w_H[n]=0.54-0.46\cos\left(\frac{2\pi n}{L-1}\right),
\quad 0\leq n\leq L-1
\]

Here, \(L\) represents the number of window samples. The FIR filter coefficients are designed in MATLAB using `fir1()` and the Hamming window generated by `hamming(L)`.

### 4. Low-pass filter specifications

The passband edge frequency is the lowest input frequency:

\[
f_p=10\,\text{Hz}
\]

The stopband edge frequency is selected as 1.4 times the passband edge:

\[
f_{st}=1.4f_p=1.4\times10=14\,\text{Hz}
\]

The transition band is the frequency range between 10 Hz and 14 Hz.

The normalized transition width is:

\[
\Delta f=\frac{f_{st}-f_p}{F_s}
=\frac{14-10}{120}
=0.0333
\]

The normalized passband and stopband edge frequencies used by `fir1()` are:

\[
W_p=\frac{2f_p}{F_s}
=\frac{2\times10}{120}
=0.1667
\]

\[
W_{st}=\frac{2f_{st}}{F_s}
=\frac{2\times14}{120}
=0.2333
\]

The normalized cutoff frequency is taken as the midpoint:

\[
W_c=\frac{W_p+W_{st}}{2}
=\frac{0.1667+0.2333}{2}
=0.2
\]

In MATLAB, a normalized cutoff of 1 corresponds to the Nyquist frequency \(F_s/2\). Therefore, the cutoff frequency in hertz is:

\[
f_c=W_c\frac{F_s}{2}
=0.2\times60
=12\,\text{Hz}
\]

### 5. Filter length and order

The approximate Hamming-window filter length is calculated using:

\[
L=\left\lceil\frac{3.3}{\Delta f}\right\rceil
=\left\lceil\frac{3.3}{0.0333}\right\rceil
=99
\]

The filter order is one less than the filter length:

\[
M=L-1=99-1=98
\]

The filter therefore has 99 coefficients and an order of 98.

### 6. MATLAB functions used

- `hamming(L)` generates a Hamming window containing \(L\) samples.
- `fir1(M,W_c,'low',window)` designs the low-pass FIR filter.
- `freqz(b,a)` displays the filter's magnitude and phase frequency responses.
- `filter(b,a,x)` applies the filter to the input signal.
- `fft()` calculates the Discrete Fourier Transform to examine the frequency components.
- `abs()` calculates the magnitude of the FFT values.

## Algorithm

1. Clear the command window and workspace, and close all open figures using `clc`, `clear`, and `close all`.
2. Define the input frequencies as \(f_1=10\,\text{Hz}\), \(f_2=20\,\text{Hz}\), and \(f_3=30\,\text{Hz}\).
3. Calculate the sampling frequency \(F_s=4f_{\max}=120\,\text{Hz}\), and create the time vector \(t=0:T_s:1\), where \(T_s=1/F_s\).
4. Generate the three sinusoidal signals and add them to obtain the composite input \(x(t)\).
5. Set the passband edge to \(f_p=10\,\text{Hz}\) and the stopband edge to \(f_{st}=14\,\text{Hz}\).
6. Calculate the normalized transition width, normalized cutoff frequency, filter length \(L\), and filter order \(M=L-1\).
7. Generate the Hamming window using `hamming(L)` and design the low-pass FIR filter using `fir1()`.
8. Plot the magnitude and phase frequency responses using `freqz(b,a)`.
9. Apply the filter to the composite signal using `filter(b,a,x)`.
10. Calculate the FFT magnitudes of the original and filtered signals, create the corresponding frequency axis, and plot the input and output spectra.
11. Compare the spectra and observe which frequency components have been attenuated.

## Conclusion

The low-pass FIR filter was designed and implemented using a Hamming window in MATLAB. The 10 Hz component lies in the passband and is intended to pass, while the 20 Hz and 30 Hz components lie in the stopband and are attenuated. The frequency response and FFT plots are used to observe the filtering result. The Hamming window reduces sidelobes compared with a rectangular window.
